# Task 1 – Python Foundations

This repository contains my solution for three Level of tasks Python programs that demonstrate core programming concepts such as functions, loops, conditionals, and user input/output. Each script is designed to be run from the command line and showcases practical problem‑solving.

## Implementations

### 1. Factorial Calculator
**Description:**  
Prompts the user for a number and computes its factorial using iterative multiplication.  

**Concepts Used:**  
- Function definition  
- Loops (iteration)  
- Arithmetic operations  
- Input/output handling  

---

### 2. Vowel Counter
**Description:**  
Takes a string input and counts the number of vowels (`a, e, i, o, u`) present, ignoring case sensitivity.  

**Concepts Used:**  
- Function definition  
- String manipulation (`lower()`)  
- Loops and conditionals  
- Membership testing (`in`)  

---

### 3. CLI‑Based Calculator
**Description:**  
A command‑line calculator that performs addition, subtraction, multiplication, and division. It includes error handling for invalid operations and division by zero. The program runs in a loop until the user chooses to exit.  

**Concepts Used:**  
- Function definition  
- Loops (`while True`)  
- Conditional branching (`if/elif/else`)  
- Arithmetic operations  
- Error handling  
- Control flow (`break`, `continue`)  

---

##  How to Run
1. Clone or download the repository.  
2. Open the `.py` file in your Python environment.  
3. Run the script and follow the prompts in the terminal.
